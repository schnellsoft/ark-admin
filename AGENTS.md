## Remember
In the following description by sndgrid I mean a grid with:
   - save button that trigger the reflection of operations on it to database and corresponding json file  
   - search
   - bottom page navigation with possibility to select the number of records per page. This number should be memorized for each grid.
   - all CRUD operations possible
   - reposition by using, at the top, a reposition form that consist by two input texts of type number (strict positive) and a "Ok" button. First input is showing "From" as placeholder, second "To". First represent the position of the selected record to be removed and the second is showing the position where the new record will be moved. After I press "Ok" the reposition becomes visible in grid and the form is reset.
